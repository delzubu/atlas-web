# Assistant

Open Assistant to ask a question about your work or request a change while you have an Atlas page open. The panel can pass context from the page to a hosted agent. The actions the agent can take depend on its connected toolkits and permissions.

## How to use Assistant

1. Save open drafts, then select the Assistant tab at the edge of the screen or press **Ctrl+.** (**⌘+.** on macOS). On first use, connect the Atlas agent and configure the provider key in **Settings** if your setup requires it.
2. Ask a question or describe the change you want. The conversation can include your current app, workspace and selection. Name any other document or workspace the agent should use.
3. If prompted, authorise the relevant toolkit. When the agent finishes, review what changed and follow the links to inspect its work.

Assistant uses the hosted agents and toolkits configured for your instance. Use **Threads** to resume a conversation or **New thread** to start another.

## Use the agent that fits your task

Assistant is one way to interact with Atlas, not a requirement for using its tools. You can also connect compatible external MCP clients, including agents from different AI providers, and work on the same authorised Atlas projects. Your saved artifacts remain in Atlas when you change clients. The built-in Assistant's hosted provider options depend on your instance configuration; external clients have their own subscription and capability requirements.

## Playbooks supporting work

If the configured agent has Workspace and the required toolkit access, ask it to follow one of the [Atlas playbooks]({{ site.baseurl }}{% link docs/playbooks/index.md %}). Name the workflow and give it the relevant inputs.
