# Apps

Atlas is a suite of apps that share one shell and one document store, the Workspace. Add one page per app in this folder, each with `parent: Apps`.

Check each app's own `AGENTS.md` in the Atlas repositories before documenting what it can do: verify current capability before making feature claims.
