# Apps

Choose the instrument that fits the work. Atlas shares a persistent workspace across compatible people and agents; specialised apps offer additional representations and operations. Availability depends on the installed modules, enabled apps and your access.

## Collaborate and organise

- [Workspace]({{ site.baseurl }}{% link docs/apps/workspace.md %}) — Create and revise shared artifacts, organise sources, comments and project history.
- [Assistant]({{ site.baseurl }}{% link docs/apps/assistant.md %}) — Interact with a configured hosted agent from the working surface; external compatible agents are also supported.
- [Planner]({{ site.baseurl }}{% link docs/apps/planner.md %}) — Build schedules, dependencies, milestones and chronologies.

## Research and maintain knowledge

![Knowledge base navigation and highlights]({{ site.baseurl }}{% link docs/developers/design/screenshots/kb-files-highlights.png %})

- [Knowledge base]({{ site.baseurl }}{% link docs/apps/knowledge-base.md %}) — Navigate articles, timelines and explicit relationships.
- [Search]({{ site.baseurl }}{% link docs/apps/search.md %}) — Retrieve relevant passages and evidence from indexed collections using hybrid semantic retrieval.

[Choose between KB and Search]({{ site.baseurl }}{% link docs/articles/kb-versus-search.md %}).

## Analyse and design

- [Causal]({{ site.baseurl }}{% link docs/apps/causal.md %}) — Explore cause, effect, feedback loops and interventions.
- [UML]({{ site.baseurl }}{% link docs/apps/uml.md %}) — Maintain software design diagrams.
- [Stakeholders]({{ site.baseurl }}{% link docs/apps/stakeholders.md %}) — Understand project participants and their relationships.

## Learn and practise

- [Study]({{ site.baseurl }}{% link docs/apps/study.md %}) — Turn source material into readings, learning paths and tests.
- [Languages]({{ site.baseurl }}{% link docs/apps/languages.md %}) — Practise vocabulary, grammar and phrases.

## Create worlds and places

- [Map]({{ site.baseurl }}{% link docs/apps/map.md %}) — Explore the Greyhawk world map.

## Administration and integrations

- [Identity]({{ site.baseurl }}{% link docs/apps/identity.md %}) — Sign-in, account and access management.
- [Oppos]({{ site.baseurl }}{% link docs/apps/oppos.md %}) — Review opportunities in a configured sales-system integration.

## Browse by software module

The navigation retains the software module groupings: [Core]({{ site.baseurl }}{% link docs/apps/core.md %}), [Hobby]({{ site.baseurl }}{% link docs/apps/hobby.md %}) and [Work]({{ site.baseurl }}{% link docs/apps/work.md %}). These describe repository and deployment boundaries, not restrictions on how you can use a tool. A Core app can still require optional infrastructure, and a Hobby tool can support professional work.

See [Getting started]({{ site.baseurl }}{% link docs/getting-started.md %}) for access and [Deployment]({{ site.baseurl }}{% link docs/developers/deployment.md %}) for installation details.
