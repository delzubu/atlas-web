# Map

Use Map to find places, follow routes, and view regions and layers on the Greyhawk world map. You can also measure distances and, with access to edit, maintain points of interest, paths, and regions.

## How to use Map

1. Open Map and use the navigator to find a layer. Select a point, path or region to inspect it.
2. Use the available distance and layer controls to understand where places lie and how they relate.
3. With edit access, use the navigator toolbar or command palette to add a point, path or region.

Map works with the existing Greyhawk world map. Use Mapper when authoring a separate detailed map for a town, site or building.
