# Mapper

Use Mapper to lay out roads, terrain, buildings, and other features with reusable objects and map rules. Edit the map in the browser and render it as an image or export it as DXF. Maps are stored in an Atlas workspace.

## How to use Mapper

1. Open a map from the picker or follow an Atlas link to it. A map lives in a Workspace project.
2. Select an object in the navigator and use the inspector to see its details. Enter **Edit mode** to add or change objects.
3. Use the library and template tools to build up the map, then render it as a PNG or export it as DXF.

Mapper stores map objects with stable identifiers and supports terrain, placement rules and generated layouts. Use it to model a town, site, building or another spatial layout.
