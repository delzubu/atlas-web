# Planner

Use Planner to break work into tasks, set dependencies and milestones, and account for working calendars and resource assignments. The Gantt chart shows how the schedule fits together. Plans live in Atlas Workspace.

## How to use Planner

1. Open the plan picker and choose a workspace and plan, or follow a link to an existing plan.
2. Switch to **Edit mode**. Add tasks and milestones, set dependencies and calendars, then use the Gantt chart and task table to inspect the schedule.
3. Set a workspace as your personal project and use **Open my TODOs** to manage your own actions. Project tasks can also carry TODOs.

Planner has import paths for CSV, Microsoft Project XML and Jira. Use swimlanes for a chronology or plan presentation and baselines to compare the schedule to a saved reference.

## Try a small planning exercise

Ask an agent with Planner and Workspace access to create a plan for an event with a fixed opening date. Include preparation, review, production and installation, and link tasks that depend on one another. Ask it to state assumptions about durations and calendars. Open the plan, inspect the Gantt chart, and change one assumption to see which dates are affected. Review the resulting schedule rather than treating the first calculation as a commitment.

The [Gantt reference preview]({{ site.baseurl }}{% link docs/developers/design/previews/Gantt.html %}) illustrates the shared chart design; it is not an interactive plan. Use the [structured co-creation workflow]({{ site.baseurl }}{% link docs/articles/structured-co-creation.md %}) when the plan is one of several evolving project artifacts.
