# Planner

Use Planner to break work into tasks, set dependencies and milestones, and account for working calendars and resource assignments. The Gantt chart shows how the schedule fits together. Plans live in Atlas Workspace.

## How to use Planner

1. Open the plan picker and choose a workspace and plan, or follow a link to an existing plan.
2. Switch to **Edit mode**. Add tasks and milestones, set dependencies and calendars, then use the Gantt chart and task table to inspect the schedule.
3. Set a workspace as your personal project and use **Open my TODOs** to manage your own actions. Project tasks can also carry TODOs.

Planner has import paths for CSV, Microsoft Project XML and Jira. Use swimlanes for a chronology or plan presentation and baselines to compare the schedule to a saved reference.
