# UML

Use UML to edit PlantUML and Mermaid source with a live preview. Keep class, C4, sequence, state, and activity diagrams together in a workspace model, and use the outline and validation tools to inspect the model as it changes.

## How to use UML

1. Open a workspace model. Choose **New diagram** and select a kind such as class, C4, sequence, state or activity.
2. Edit the PlantUML or Mermaid source and inspect the live preview. Check any validation issues before saving.
3. Save the model or export a diagram as SVG, PNG or source text. Agents with access can make checked edits to the same model.

The model folder keeps diagram source and related design notes together, so the team can edit or review them in Workspace.
