# 2026.11.24
{: .release-date }

## Core 1.1.3
{: .release-module }

Search can connect to Neo4j Query API addresses that specify a custom HTTPS port. This release also points readers from in-app Workspace and Search help to the public task guides.

- HTTPS database connections use the port in the address and default to 443 when none is supplied. [Core 1.1.3 comparison](https://github.com/delzubu/atlas-core/compare/core-v1.1.2...core-v1.1.3)
- Moved the local Neo4j setup walkthrough and Workspace checkout and migration procedures to the public guides. [Workspace guide]({{ site.baseurl }}{% link docs/apps/workspace.md %})

## Core 1.1.2
{: .release-module }

Search writers can temporarily connect their own Neo4j database and query it from the web app or an agent. The new graph-query playbook helps an agent inspect the schema and use the graph as evidence for an answer.

- Connect a database over HTTPS, edit its address to reconnect, or disconnect it when finished. Connections expire after a day without use. [Temporary databases](https://github.com/delzubu/atlas-core/pull/31) · [Reconnecting](https://github.com/delzubu/atlas-core/pull/35)
- Use keyword, vector and read-only Cypher queries on your graph. Inspect labels, relationship types and indexes in Statistics. [Query your own graph database]({{ site.baseurl }}{% link docs/playbooks/core.md %}#query-your-graph)
- Added a guide to connecting Neo4j from your computer and updated HTTPS requests to use the Query API’s supported fields. [Connection guide](https://github.com/delzubu/atlas-core/pull/32) · [Query API compatibility](https://github.com/delzubu/atlas-core/pull/33)
- Identity can create missing known storage containers on first use and shows a sign-in error when Microsoft sign-in is refused. Search reports storage failures as service unavailable. [Identity and Search fixes](https://github.com/delzubu/atlas-core/pull/34)

## Core 1.1.1
{: .release-module }

Core 1.1.1 packages the Search integration introduced in 1.1.0 as a tagged release.

- Updated the versions of the shared Python and npm packages and Workspace.
- Published the matching App Suite and Catalog npm tags. [Core 1.1.1 tag](https://github.com/delzubu/atlas-core/tree/core-v1.1.1)

## Core 1.1.0
{: .release-module }

Atlas Search moved into Core. People and agents can search configured knowledge indexes from one place. This version also introduced a deployment settings provider and let operators select which edition apps to deploy.

- Added the Search web app, REST API and MCP tools for querying, refining results, checking index statistics and curating indexed knowledge. [Search integration](https://github.com/delzubu/atlas-core/pull/28)
- Connected Search to Look up, Workspace project home and Assistant. Added a staged progress display and database management in Search. [Search interface](https://github.com/delzubu/atlas-core/pull/29)
- Added an optional settings provider that populates instance environment files and records values learned during deployment. [Environment provider](https://github.com/delzubu/atlas-core/pull/25)
- Added per-instance app selection for edition deployments. [App selection](https://github.com/delzubu/atlas-core/pull/27)

## Work 1.0.0
{: .release-module }

Work reached its first major version as an independently deployable edition using released Core packages. Oppos added delivery tasks to Overview and refined account access and reporting.

- Resolve Core at setup and deploy Work on its own host, with optional settings-provider support and per-instance app selection. [Settings provider](https://github.com/delzubu/atlas-work/pull/6) · [App selection](https://github.com/delzubu/atlas-work/pull/8)
- Show unlinked delivery tasks by default in Oppos Overview. Editors can link a task to an opportunity, with its Oppos notes carried across and restored on unlink. [Link delivery tasks](https://github.com/delzubu/atlas-work/pull/10)
- Scope readers and reviewers to assigned accounts, improve wins and losses in period reports, and use MCP v2 for Oppos. [Access and reporting](https://github.com/delzubu/atlas-work/pull/9)
- Moved task walkthroughs for Causal, Stakeholders and UML to the public guides. [Work apps]({{ site.baseurl }}{% link docs/apps/work.md %})
