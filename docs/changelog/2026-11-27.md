# 2026.11.27
{: .release-date }

## Core 1.2.0
{: .release-module }

Atlas Search now handles indexing and curation through its own API and adds a dedicated `search-intake` CLI. Databases can hold documents, indexed Python code, or other graphs. Administrators can configure how existing graphs expose datasets and select models per database.

- Index documents and Python source from the command line. Document intake can resume after interruption and report progress as it captures, embeds and indexes material. [Search guide]({{ site.baseurl }}{% link docs/apps/search.md %}#index-documents-or-python-code)
- Queue document intake from Search and process it with a worker. Search applies writes and curation through its own API.
- Choose what a database holds, preview dataset definitions for existing graphs, and manage model and connection options in database settings. [Search migration and database settings](https://github.com/delzubu/atlas-core/pull/36)
- Configure inference in Identity and choose embedding and reranker models per database. Searches across databases can combine rankings from different rerankers. [Reranker selection](https://github.com/delzubu/doc-indexer/pull/189)
