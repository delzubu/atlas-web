# SDK

This section will cover building apps and integrations with Atlas.

- **Python services.** Shared packages, app registration, authentication, and the Identity port.
- **Document apps.** Workspace storage, document descriptors, and revision checks.
- **Web apps.** The shared React shell, sign-in, navigation, and `atlas://` links.
- **API and agent integrations.** REST resources, OpenAPI contracts, and MCP tools.

For now, start with [Modules]({{ site.baseurl }}{% link docs/developers/modules.md %}) to locate the packages and follow the relevant package README or the contracts in Core's `docs/specs/`.
