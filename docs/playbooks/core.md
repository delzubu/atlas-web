# Core playbooks

Use the Core playbook to establish a new workspace knowledge base with an agent. Start in [KB Explorer]({{ site.baseurl }}{% link docs/apps/knowledge-base.md %}) or create a project from the Knowledge base template.

## Knowledge bases

### Set up a knowledge base
{: #setup-knowledge-base }

Give the agent the subject, audience and any starter sources. It sets up the workspace knowledge base, agrees on folders and tags, records conventions, seeds the first articles and checks the indexes.

Playbook ID `setup-knowledge-base`.
