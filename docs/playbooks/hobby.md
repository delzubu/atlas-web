# Hobby playbooks

Hobby playbooks help you turn lesson notes into practice, source material into study paths, and campaign ideas into researched world material and character records. Choose the playbook that matches your current stage of work. See the [Hobby apps]({{ site.baseurl }}{% link docs/apps/hobby.md %}) to find where you’ll work with the results.

## Language practice

### Set up a language project
{: #setup-language-project }

Provide the language pair, starting level and goals. The agent records teaching preferences and prepares the lesson register.

Playbook ID `setup-language-project`.

### Build a language lesson
{: #build-language-lesson }

Share lesson notes, a handout or a word list. The agent builds vocabulary, grammar and exercises, checks that the lesson can be practised, and reports any assumptions.

Playbook ID `build-language-lesson`.

### Grade language answers
{: #grade-language-answers }

Use when translations are waiting for review. The agent assesses meaning, grammar and word choice, and explains corrections to the learner.

Playbook ID `grade-language-answers`.

## Study

### Set up a learning project
{: #setup-learning-project }

Describe the audience, goals, teaching language and prior knowledge. The agent records teaching instructions and prepares a register for multiple Study corpora.

Playbook ID `setup-learning-project`.

### Build study material
{: #build-study-path }

Give the agent a body of material and a learning goal. It coordinates intake, path design and test authoring across the teaching playbooks.

Playbook ID `build-study-path`.

### Intake a study corpus
{: #intake-study-corpus }

Supply source documents or a knowledge collection. The agent preserves the source text, records provenance and builds indexes to support path design.

Playbook ID `intake-study-corpus`.

### Design study paths
{: #design-study-paths }

Start with an indexed corpus and a learner audience. The agent plans objectives, guided readings and practice, and shows how the paths cover the source material.

Playbook ID `design-study-paths`.

### Build a study test
{: #build-study-test }

Choose a path to assess. The agent drafts varied questions and evidence-based scoring criteria, then checks the questions for clues and ambiguity.

Playbook ID `build-study-test`.

### Grade study answers
{: #grade-study-answers }

Use for written answers awaiting scoring. The agent checks them against the pinned corpus and rubric and returns feedback and partial credit.

Playbook ID `grade-study-answers`.

## Worldbuilding

### Research, model and write a world element
{: #rpg-research-model-output }

Choose a place, institution or other element to develop. Work with the agent through research, model building, review and writing for the intended audience.

Playbook ID `rpg-research-model-output`.

### Research a D&D topic
{: #dnd-research-topic }

Frame a Greyhawk question with the agent. It gathers sources and records findings by topic, with gaps and disagreements marked.

Playbook ID `dnd-research-topic`.

### Validate a world model
{: #dnd-validate-world-model }

Give the agent a model or claim to review. It checks plausibility, canon and consistency, and reports what needs revision.

Playbook ID `dnd-validate-world-model`.

### Model relations
{: #model-relations }

Choose a workspace folder of dossiers. The agent extracts supported relationships into article headers so KB Explorer can show them as a graph.

Playbook ID `model-relations`.

### Write D&D material
{: #dnd-write-output }

Use reviewed material to draft read-aloud text, DM-facing material or setting background. Give the agent the output type and the source sections to use.

Playbook ID `dnd-write-output`.

## Campaign characters

### Create an NPC
{: #dnd-create-npc }

Give the agent the character’s role and setting. It checks campaign context and relevant canon, then drafts a character sheet.

Playbook ID `dnd-create-npc`.

### Create a campaign group
{: #dnd-create-group }

Describe the group’s region and agenda. The agent drafts its organisation, ties, plans and clocks in the campaign register.

Playbook ID `dnd-create-group`.

### Develop an NPC or group
{: #npc-develop }

Choose an existing sheet and the sections to develop. Work through those sections individually, using the established campaign material.

Playbook ID `npc-develop`.

### Voice an NPC
{: #npc-voice }

Name the character and who is speaking to them. The agent uses the sheet to play the conversation and flags what may be worth recording.

Playbook ID `npc-voice`.

### Update NPCs after a session
{: #npc-after-session }

Give the agent session notes or an account of events. Review proposed changes to appearances, ties, attitudes, clocks and history before they are recorded.

Playbook ID `npc-after-session`.

### Run a faction turn
{: #npc-faction-turn }

Set the in-world date to advance to. Review what factions might do and which clocks should move before recording the turn.

Playbook ID `npc-faction-turn`.

## Personalisation

### Customise a mascot
{: #customize-mascot }

Choose a project, Study corpus or path, or Languages pair or lesson. The agent can change the mascot, backdrop and accessories, add your own images, or turn the mascot off.

Playbook ID `customize-mascot`.
