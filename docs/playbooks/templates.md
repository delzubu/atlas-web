# Project templates

A project template gives [Workspace]({{ site.baseurl }}{% link docs/apps/workspace.md %}) a starting structure. It can supply folders, starter documents, prompts, project references and instructions for agents. You can edit these files after creating the project.

## Start from a template

1. In Workspace, choose **New project from template** on the welcome screen, or **New from template…** in the Open dialogue.
2. Choose a template, name the project and fill in the fields it asks for.
3. Open the new project and review its starter files. If it has a setup playbook, use the project’s setup guidance to start that workflow with an agent.

The list reflects the templates installed on your instance.

## Core

- **Knowledge base** creates a project for a workspace knowledge base. Use [Set up a knowledge base]({{ site.baseurl }}{% link docs/playbooks/core.md %}#setup-knowledge-base) to agree on its organisation, vocabulary and first articles.

## Hobby

- **D&D module** starts an adventure with maps, a session plan, an inbox and prompts for use at the table.
- **Language learning** records the language pair, level and goals. Use [Set up a language project]({{ site.baseurl }}{% link docs/playbooks/hobby.md %}#setup-language-project) to tailor the project.
- **Learning project** organises learning goals, sources and a register of Study corpora. Use [Set up a learning project]({{ site.baseurl }}{% link docs/playbooks/hobby.md %}#setup-learning-project) to agree on how learners will use the material.
- **RPG worldbuilding** provides separate areas for inputs, research, the world model and written output. Use [Research, model and write a world element]({{ site.baseurl }}{% link docs/playbooks/hobby.md %}#rpg-research-model-output) to develop an element through those stages.

## Work

- **Generic work** starts an ad-hoc project with inputs, mail, materials, output, a TODO plan and a handoff file.
- **Presales pursuit** starts a response workspace with a brief, decisions and working documents. Use [Plan a presales pursuit]({{ site.baseurl }}{% link docs/playbooks/work.md %}#plan-presales-pursuit) to build the schedule.
- **Work package proposal** provides a proposal structure with scope, delivery plan, notes and drafting and review prompts. See [Write a proposal]({{ site.baseurl }}{% link docs/playbooks/work.md %}#write-proposal) and [Review a proposal]({{ site.baseurl }}{% link docs/playbooks/work.md %}#review-proposal).
