# Work playbooks

Work playbooks help teams plan a pursuit, prepare decisions and conversations, and draft or review material together. Start with a workspace and the relevant brief, notes or draft so the agent can work from the same material you do. See the [Work apps]({{ site.baseurl }}{% link docs/apps/work.md %}) for tools to inspect models, relationships and opportunities.

## Pursuits and proposals

### Plan a presales pursuit
{: #plan-presales-pursuit }

Provide the response type, submission date and people available. The agent works back from submission to create a day-by-day Planner schedule with roles, review gates and deliverables.

Playbook ID `plan-presales-pursuit`.

### Sharpen competitive positioning
{: #sharpen-competitive-positioning }

Share the client priorities and competitors you know about. The agent tests differentiators, develops win themes and records the evidence and likely counterclaims.

Playbook ID `sharpen-competitive-positioning`.

### Write a proposal
{: #write-proposal }

Supply the brief and the kind of document you need. The agent drafts the proposal or section in Workspace and can prepare a compliance matrix for an RFP.

Playbook ID `write-proposal`.

### Review a proposal
{: #review-proposal }

Give the agent the draft and the brief it answers. It returns prioritised findings and suggested rewrites.

Playbook ID `review-proposal`.

### Write a board task description
{: #write-board-task-description }

With access to the opportunity and board, ask the agent to prepare a task from the opportunity record and apply the board’s description format. Review the proposed details before updating the task.

Playbook ID `write-board-task-description`.

## Stakeholders and meetings

### Map stakeholders
{: #map-stakeholders }

Describe the initiative and provide what you know about its participants. The agent prepares a stakeholder map, engagement actions and risks.

Playbook ID `map-stakeholders`.

### Prepare or debrief a meeting
{: #prepare-meeting }

Give the agent the attendees, objective and context. It creates a preparation file for the meeting, or a debrief with follow-up actions after it happens.

Playbook ID `prepare-meeting`.

### Prepare a difficult conversation
{: #prepare-difficult-conversation }

Describe the message or negotiation. The agent helps prepare an opening, anticipate objections and decide what you can concede.

Playbook ID `prepare-difficult-conversation`.

### Tailor a message to an audience
{: #tailor-message-to-audience }

Identify the audience and what you want them to understand or do. The agent develops a message, email or talking points for that audience.

Playbook ID `tailor-message-to-audience`.

### Prepare a steering committee update
{: #prepare-steerco-update }

Share the project status and the audience. The agent frames overall health, issues, decisions and the next reporting period.

Playbook ID `prepare-steerco-update`.

## Presentations

### Plan a deck storyline
{: #plan-deck-storyline }

Provide the audience, decision and slot. The agent makes a brief with the main argument, the sequence of slide titles and one message per slide.

Playbook ID `plan-deck-storyline`.

### Design a slide
{: #design-slides }

Give the agent a slide brief or a slide to fix. It produces one editable HTML slide in Workspace using the selected design template.

Playbook ID `design-slides`.

### Review a deck
{: #review-deck }

Share a draft deck and its audience. The agent reviews the story, slide design and presentation readiness, and prioritises fixes.

Playbook ID `review-deck`.

### Prepare a talk track
{: #prepare-talk-track }

Provide a finished deck, audience and time slot. The agent prepares slide-by-slide wording, likely questions and, if needed, a demo and contingency plan.

Playbook ID `prepare-talk-track`.

### Workshop a spoken pitch
{: #workshop-pitch }

Describe what you are pitching and to whom. The agent develops versions at several lengths, prepares likely questions and makes a short version to keep at hand.

Playbook ID `workshop-pitch`.
